# 表达式与全部算子规定

返回[研究者指南](../README.md)。所有算子都作用于“日期×股票”矩阵，数值常量自动广播。点运算按同日同股计算，`Rank` 横向跨股票计算，`Ts*` 纵向只使用该股票的历史。

## 语法和公共规则

使用 `算子(参数,...)`、`$feature` 和有限数值；允许负常量及科学计数法。不支持 Python 属性、下标、导入、函数执行、关键字参数、条件表达式或中缀 `+ - * /`。例如写 `Div(Sub($close,$open),$open)`。为兼容旧表达式，裸字段名 `close` 和 `open_` 也接受，推荐统一用 `$close/$open`。

支持的字段：`$open,$high,$low,$close,$amt,$num_trades,$cumadj,$vwap,$volume`。最后两者是有明确告知的代理，详见 README。其余未知字段直接报错，不自动猜测替代。

以下记号中：`x_t` 是当日值，窗口 `W_n(t)=[x_(t-n+1),...,x_t]` 含当天，`mean` 是算术平均，`s` 是样本标准差（分母 `n-1`），`m_k=mean((x-mean(x))^k)`。窗口单位都是**数据日历中的交易日**，不是自然日。统计窗口内任何一项缺失则结果缺失；`Ref/TsDelta/TsPctChange` 只引用指定端点，中间未参与计算的观测缺失不会影响它们。不采用 `min_periods=1`，也不向未来回填。

窗口参数必须是数值字面量整数，通常为 `[1,2000]`；`Ref` 可以为零。拒绝负窗口与负 `Ref`，防止表达式偷看未来。嵌套回溯长度递归相加：`TsMean(Ref($close,5),20)` 需要 24 个历史交易日。表达式最长 8192 字符、最多 512 个 AST 节点。长度限制用于尽早指出误输入，不影响本项目的示例池。

除零、溢出、无实数定义的幂、无定义对数、无定义方差和相关性转为 `NaN`；所有算子内部统一清理无穷值。系统不会为分母悄悄加 epsilon，需要保护时自己写 `Add(分母,1e-8)`；有时分母为负，这种保护也需要由研究者判断是否合理。

## 单目算子（1 个参数）

| 语法 | 精确定义 |
|---|---|
| `Abs(x)` | `abs(x)` |
| `SLog1p(x)` | `sign(x)*log(1+abs(x))`，有符号压缩 |
| `Inv(x)` | `1/x` |
| `Sign(x)` | 负数为 -1，零为 0，正数为 1 |
| `Log(x)` | 自然对数，只对 `x>0` 有定义 |
| `Rank(x)` | 每日有限股票升序平均秩：`(rank_1based-1)/有效股票数`；并列取平均，缺失保持缺失 |

`Rank([1,1,3])=[1/6,1/6,2/3]`。它不是 z-score。Rank 表达式在进入组合前仍执行统一的截面标准化。

## 双目算子（2 个参数）

| 语法 | 精确定义 |
|---|---|
| `Add(x,y)` | `x+y` |
| `Sub(x,y)` | `x-y` |
| `Mul(x,y)` | `x*y` |
| `Div(x,y)` | `x/y` |
| `Pow(x,y)` | 实数幂 `x**y`，负底数的非整数幂为缺失 |
| `Greater(x,y)` | 逐元素较大值 `max(x,y)`，不是布尔“大于” |
| `Less(x,y)` | 逐元素较小值 `min(x,y)`，不是布尔“小于” |
| `GetGreater(x,y)` | `Greater` 的别名，兼容已有 pool |
| `GetLess(x,y)` | `Less` 的别名，兼容已有 pool |

## 单序列时序算子（2 个参数）

| 语法 | 精确定义 |
|---|---|
| `Ref(x,n)` | `x_(t-n)`；`Ref(x,0)=x_t` |
| `TsDelta(x,n)` | `x_t-x_(t-n)`；需要 n 个历史日 |
| `TsPctChange(x,n)` | `x_t/x_(t-n+1)-1`；保留原工程“n 个观测首尾变化”的口径 |
| `TsMean(x,n)` | `mean(W_n)` |
| `TsSum(x,n)` | `sum(W_n)` |
| `TsStd(x,n)` | 样本标准差 `s`，`n=1` 无定义 |
| `TsVar(x,n)` | 样本方差 `s²`，`n=1` 无定义 |
| `TsIr(x,n)` | `mean(W_n)/s`，不是收益率专用算子 |
| `TsMax(x,n)` | `max(W_n)` |
| `TsMin(x,n)` | `min(W_n)` |
| `TsMinMaxDiff(x,n)` | `max(W_n)-min(W_n)` |
| `TsMaxDiff(x,n)` | `x_t-max(W_n)`，通常非正 |
| `TsMinDiff(x,n)` | `x_t-min(W_n)`，通常非负 |
| `TsMed(x,n)` | 中位数，偶数窗口取中间两个数的平均 |
| `TsMad(x,n)` | `mean(abs(W_n-mean(W_n)))`，相对均值的平均绝对偏差，不是中位数绝对偏差 |
| `TsSkew(x,n)` | `m_3/m_2**1.5`，不做小样本偏差校正 |
| `TsKurt(x,n)` | `m_4/s**4-3`；保留原工程使用样本方差的口径，与很多库的总体超额峰度不同 |
| `TsRank(x,n)` | 最新值在窗口内的**降序**平均秩/`n`；最大为 `1/n`、最小为 1，保留原工程方向 |
| `TsDiv(x,n)` | `x_t/mean(W_n)` |
| `TsWMA(x,n)` | 权重从最旧到最新为 `0,1,...,n-1`，归一化加权；保留原工程最旧观测权重为零的定义 |
| `TsEMA(x,n)` | 有限窗口加权：`a=1-2/(n+1)`，权重从最旧到最新为 `a**n,...,a**1`，再归一化；不是无限递推 EWM |

几个容易混淆的例子：

```text
Ref($close,5)                    五个交易日前的收盘价
TsDelta($close,5)                当前减五个交易日前
TsPctChange($close,6)            五日收益率
TsPctChange($close,2)            一日收益率
TsMean($close,5)                 今天及之前四日的均值
TsDiv($close,20)                 当前价格相对二十日均价
```

`TsRank` 示例：窗口 `[1,2,3]` 返回 `1/3`；窗口 `[3,2,1]` 返回 1；`[1,1,1]` 返回 `2/3`。方向与 `Rank` 不同是原 pool 的约定，不能自行改成升序而继续声称同一表达式。

单点窗口约定：`TsMean/TsSum/TsMax/TsMin/TsMed/TsWMA/TsEMA(x,1)=x`，`TsRank(x,1)=1`，`TsPctChange(x,1)=0`（有效非零输入），`TsMad` 与极差为零；标准差、方差、IR、标准化偏度/峰度和相关性在无定义时为缺失。

## 双序列时序算子（3 个参数）

| 语法 | 精确定义 |
|---|---|
| `TsCov(x,y,n)` | 同一股票两序列最近 n 日的样本协方差 `sum((x-mean(x))*(y-mean(y)))/(n-1)` |
| `TsCorr(x,y,n)` | 同一窗口的 Pearson 相关系数，两序列都需要完整有效窗口及非零标准差 |

`n=1` 时二者无定义。时序相关性与每日横截面的 IC 是两个概念：`TsCorr` 是表达式本身，IC 是表达式结果对未来收益的评价。

具体数值与因果性测试见 `tests/test_expressions.py`。
